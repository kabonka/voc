# Voc — 五年級 HTBS 英文單字學習 App

一個**單文件、自包含**的英文單字互動學習網頁，適用於五年級 HTBS 課程單字複習。

## 使用方法

直接用瀏覽器打開 `voc.html` 即可（無需安裝、無外部依賴）。

### 功能

- **學習模式**：顯示單字 + 詞性 + 英文定義 + 例句 + 中文翻譯，每個單字配一張 emoji 例圖
- **聽寫測驗模式**：自我檢測
- **點擊發音（TTS）**：點擊單字 / 定義 / 例句即播放語音。每個單字已**預先生成本地語音檔**（`audio/` 資料夾），任何瀏覽器（含手機本机瀏覽器，如 OPPO）都能正常發聲、可離線；若本机瀏覽器支援語音合成則自動以 Web Speech API 備援。播放時文字以藍色高亮標示（不閃爍）
- **中文顯隱切換**：專注英文或對照中文
- **右側圖例面板**：說明各區塊含義
- **資料來源 / 說明面板**：顯示單字總數、來源 PDF、匯入日期，並內嵌兩個單字大會考音檔播放器

## 檔案結構

| 檔案 | 說明 |
|------|------|
| `voc.html` | App 本體（279 個單字，資料內嵌於 `wordList` 陣列） |
| `audio/` | 預先生成的本地語音檔（`wNNN_word.mp3` / `wNNN_def.mp3` / `wNNN_sent.mp3`，共 837 個），由 `gen_audio.py` 產生 |
| `1.pdf` | 單字來源表（G5 單字大會考，原 263 字） |
| `0617 G5 單字大會考 p1 已修改 (soup).mp3` | 單字大會考音檔 p1 |
| `G5 單字大會考 p2.mp3` | 單字大會考音檔 p2 |

> 語音檔為主要發聲來源，需與 `voc.html` 放在同一資料夾（本專案根目錄）才能播放。

## 技術

- 純 HTML / CSS / JavaScript，單一檔案，無框架、無外部套件
- 語音朗讀優先播放本地預生成語音檔（`audio/`，由 Edge TTS 產生）；若本机瀏覽器支援則以 Web Speech API（`speechSynthesis`）備援
- 單字資料存放於 `voc.html` 內的 `wordList` 陣列，每筆含 `word / pos / def / sent / zh / emoji` 六個欄位
- `gen_audio.py`：用 `edge-tts` 依 `words.json` 重新生成 `audio/` 語音檔（可重跑，已存在者跳過）
