# Voc — 五年級 HTBS 英文單字學習 App

一個**單文件、自包含**的英文單字互動學習網頁，適用於五年級 HTBS 課程單字複習。

## 使用方法

直接用瀏覽器打開 `voc.html` 即可（無需安裝、無外部依賴）。

### 功能

- **學習模式**：顯示單字 + 詞性 + 英文定義 + 例句 + 中文翻譯，每個單字配一張 emoji 例圖
- **聽寫測驗模式**：自我檢測
- **點擊發音（TTS）**：點擊單字 / 定義 / 例句，分別以英文朗讀（Web Speech API），播放時文字以藍色高亮標示（不閃爍）
- **中文顯隱切換**：專注英文或對照中文
- **右側圖例面板**：說明各區塊含義
- **資料來源 / 說明面板**：顯示單字總數、來源 PDF、匯入日期，並內嵌兩個單字大會考音檔播放器

## 檔案結構

| 檔案 | 說明 |
|------|------|
| `voc.html` | App 本體（279 個單字，資料內嵌於 `wordList` 陣列） |
| `1.pdf` | 單字來源表（G5 單字大會考，原 263 字） |
| `0617 G5 單字大會考 p1 已修改 (soup).mp3` | 單字大會考音檔 p1 |
| `G5 單字大會考 p2.mp3` | 單字大會考音檔 p2 |

> 音檔為唯一外部資源，需與 `voc.html` 放在同一資料夾才能播放。

## 技術

- 純 HTML / CSS / JavaScript，單一檔案，無框架、無外部套件
- 語音朗讀使用瀏覽器內建 Web Speech API（`speechSynthesis`）
- 單字資料存放於 `voc.html` 內的 `wordList` 陣列，每筆含 `word / pos / def / sent / zh / emoji` 六個欄位
